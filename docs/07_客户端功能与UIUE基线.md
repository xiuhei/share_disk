# 客户端功能与 UI/UE 基线

## Android APK

主导航固定为“文件、传输、设备、回收站”，连接与账号设置默认折叠。文件页完成发现/手工连接、初始化、登录/注销、搜索排序、文件夹、SAF 后台上传、断点下载与 Hash 校验、重命名、移动、分享、跨设备复制和删除；传输页显示 Android 后台任务及服务端复制任务并支持取消；设备页显示在线状态并可撤销其他设备；回收站支持恢复和永久删除。

交互规则：高频主操作直接显示，低频危险操作收进“更多操作”并二次确认；登录、离线、待登记、进行中、失败、完成使用明确文案；任务切页不丢传输，返回前台自动显示 WorkManager 真实状态；地址发现只填充候选，不绕过认证。

## Ubuntu DEB

Ubuntu 同时提供本机 Web UI 与完整 CLI。DEB 安装后，Agent 默认仅在 `http://127.0.0.1:9191` 提供响应式桌面页面，支持文件导入、列表、下载、重命名、删除、回收站恢复与永久删除，并显示 Agent 状态。页面上传直接流入 Agent 临时区后校验入库，不经过控制服务器；写操作检查同源，监听地址强制为 loopback。

CLI 中，`setup/login` 完成设备注册，`status`/`device status` 查看运行状态，`file import/list/show/export/verify/rename/delete` 管理文件，`trash list/restore/purge` 管理回收站，`transfer list/cancel` 管理复制任务。所有本地文件写入、导出、校验和服务端访问都经过 Agent Unix Socket，CLI 不直接修改 SQLite 或对象目录。

输出规则：默认使用稳定的单行表格便于脚本处理，详情命令展示完整 ID、Hash、大小、MIME 和状态；错误包含稳定错误码与可执行的下一步；导出默认拒绝覆盖已有文件，永久删除必须显式执行。

## 电脑 Web 管理端

可选服务端 `/admin` 提供适配桌面与窄屏浏览器的管理界面：侧栏任务导航、概览指标、可搜索文件消息表、设备在线/离线状态和撤销入口、账号资料与密码修改。只有 `conf/server.json` 的 `monitoring.enabled=true` 时才注册页面路由；关闭不影响核心业务。采用离线可用的系统字体、卡片层级、响应式表格和统一绿色综合视觉，不依赖外部 CDN。页面壳可公开访问，但所有业务数据均由 Bearer 会话保护并按账号隔离；密码只可验证后修改，永不展示明文或 Hash。

三端统一视觉规则：主色 `#126B4E`、深色 `#0C503B`、浅背景 `#F4F7F5`、白色内容卡和薄荷绿弱强调；优先展示一个主操作，危险/低频操作降级或收纳；手机使用四任务页，Ubuntu 使用文件工作台，监控端使用侧栏信息架构，但颜色、圆角、状态语义、间距和反馈文案保持一致。
