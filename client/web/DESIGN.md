# Share Disk UI/UE 设计方案

## 1. 项目概述

Share Disk 是一个自托管的分布式云盘系统，文件存储在用户自己的设备上。本文档定义了桌面端和移动端的统一UI/UE设计方案。

## 2. 设计原则

- **简约至上**: 去除冗余元素，聚焦核心功能
- **一致性**: 桌面端和移动端保持统一的视觉语言和交互逻辑
- **可访问性**: 支持键盘导航、屏幕阅读器，符合WCAG 2.1标准
- **响应式**: 移动端优先，桌面端增强

## 3. 技术选型

| 技术 | 用途 |
|------|------|
| React 18 | UI框架 |
| Tailwind CSS | 样式系统 |
| React Router | 路由管理 |
| Lucide React | 图标库 |
| Vite | 构建工具 |

## 4. 色彩系统

### 主色调 (Brand)
- **Primary**: `#10B981` (翡翠绿) - 主要操作按钮、链接
- **Primary Dark**: `#059669` - 悬停状态
- **Primary Light**: `#D1FAE5` - 背景高亮

### 中性色 (Neutral)
- **Background**: `#F9FAFB` - 页面背景
- **Surface**: `#FFFFFF` - 卡片、面板背景
- **Border**: `#E5E7EB` - 边框
- **Text Primary**: `#111827` - 主要文字
- **Text Secondary**: `#6B7280` - 次要文字
- **Text Muted**: `#9CA3AF` - 占位符文字

### 状态色 (Status)
- **Success**: `#10B981` - 成功状态
- **Warning**: `#F59E0B` - 警告状态
- **Error**: `#EF4444` - 错误状态
- **Info**: `#3B82F6` - 信息提示

## 6. 间距系统

采用8px为基础单位:
- 1: 0.25rem (4px)
- 2: 0.5rem (8px)
- 3: 0.75rem (12px)
- 4: 1rem (16px)
- 5: 1.25rem (20px)
- 6: 1.5rem (24px)
- 8: 2rem (32px)
- 10: 2.5rem (40px)
- 12: 3rem (48px)

## 7. 圆角系统

- **sm**: 0.25rem (4px) - 小元素
- **md**: 0.375rem (6px) - 按钮、输入框
- **lg**: 0.5rem (8px) - 卡片
- **xl**: 0.75rem (12px) - 大卡片、模态框
- **2xl**: 1rem (16px) - 特殊元素
- **full**: 9999px - 圆形

## 9. 功能模块

### 9.1 认证模块
- 登录/注册页面
- 记住登录状态
- 忘记密码

### 9.2 文件管理
- 文件列表（网格/列表视图切换）
- 文件上传（拖拽、点击选择）
- 文件下载
- 文件预览（图片、视频、文档）
- 文件夹管理（创建、重命名、删除）
- 文件操作（重命名、移动、复制、删除）

### 9.3 搜索与筛选
- 全局搜索
- 按类型筛选（文档、图片、视频、音频）
- 按时间排序
- 按大小排序

### 9.4 设备管理
- 已连接设备列表
- 设备状态显示
- 设备移除

### 9.5 传输管理
- 上传任务列表
- 下载任务列表
- 传输进度显示
- 任务暂停/恢复/取消

### 9.6 回收站
- 已删除文件列表
- 恢复文件
- 永久删除

### 9.7 分享管理
- 创建分享链接
- 分享链接列表
- 分享链接设置（有效期、密码）
- 取消分享

### 9.8 设置
- 账户设置
- 存储空间管理
- 主题切换（浅色/深色）

## 12. 组件规范

### 12.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | 绿色背景，白色文字 | 主要操作（上传、确认） |
| Secondary | 灰色背景，深色文字 | 次要操作（取消、返回） |
| Danger | 红色背景，白色文字 | 危险操作（删除） |
| Ghost | 透明背景，带边框 | 轻量操作（筛选） |
| Icon | 图标按钮 | 工具栏操作 |

### 12.2 输入框

- 高度: 40px (桌面) / 48px (移动)
- 边框: 1px solid #E5E7EB
- 圆角: 6px
- 聚焦: 边框色变为 #10B981，添加阴影

### 12.3 卡片

- 背景: 白色
- 边框: 1px solid #E5E7EB
- 圆角: 8px
- 阴影: shadow-sm
- 悬停: 阴影增强，边框色变化

### 12.4 模态框

- 背景遮罩: rgba(0, 0, 0, 0.5)
- 圆角: 12px
- 最大宽度: 480px (移动全屏)
- 动画: 从下方滑入

## 13. 图标规范

使用 Lucide React 图标库，统一规范:
- 尺寸: 16px (小) / 20px (中) / 24px (大)
- 颜色: 继承父元素颜色
- 描边宽度: 1.5px

## 14. 动画规范

- 过渡时间: 150ms (快速) / 200ms (正常) / 300ms (慢速)
- 缓动函数: ease-in-out
- 淡入淡出: opacity 变化
- 滑入滑出: transform + opacity
- 加载动画: 旋转或脉冲

## 15. 响应式断点

```css
/* 移动端 */
@media (max-width: 640px) { ... }

/* 平板端 */
@media (min-width: 641px) and (max-width: 1024px) { ... }

/* 桌面端 */
@media (min-width: 1025px) { ... }
```

## 16. 无障碍规范

- 所有交互元素可键盘访问
- 图片提供 alt 文本
- 颜色对比度符合 WCAG AA 标准
- 支持屏幕阅读器
- 焦点状态可见
